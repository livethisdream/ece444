# Overview

ECE 444 — **Antennas, Phased Arrays, and Radar Systems** — is a new undergraduate course Neil is teaching in **Fall 2026**. The course site is being built as a **Jupyter Book** at `~/projects/ece444/`, published to **https://livethisdream.github.io/ece444/** via the `livethisdream/ece444` GitHub repo on every push to `main` (CI: `.github/workflows/deploy.yml`, force_orphan `gh-pages`).

The site was originally scaffolded inside the Chirpy Jekyll repo at `livethisdream.github.io`, then migrated onto Jupyter Book (patterned on [usafa-ece/ece215-book](https://usafa-ece.github.io/ece215-book/)) because Chirpy fought us on reveal.js integration, math rendering, and table layouts. Reveal.js decks are preserved — served alongside the book at `/slides/<slug>.html` via Sphinx's `html_extra_path`.

Course structure: **5 modules / 41 lessons**. Module 1 Foundations (L1–6); Module 2 Antenna Types + Simulation + Measurement (L7–14, with labs); Module 3 Arrays + ADALM-PHASER Beamforming (L15–28, with labs, uses ADALM-PHASER hardware); Module 4 Radar + FMCW (L29–38, with labs); Module 5 Capstone (L39–41 — track a moving target while suppressing a static jammer). Midterm project (Antenna Pattern Measurement) is introduced at L11 and due at L20.

# Special Instructions

- The authoritative tree is `~/projects/ece444` (this repo). Older copies at `C:\...\USAFA\ece444` (OneDrive), `~/src/ece444` (WSL), and inside the historical `livethisdream.github.io` Chirpy tree are stale — do not commit to any of them.
- Keep reveal.js decks — do **not** switch to LaTeX Beamer (as ece215-book uses). The reveal.js workflow is what we want to preserve.
- Deck LaTeX gotcha: the reveal.js markdown parser eats `\<punct>` escapes inside `$…$` / `$$…$$`. Use `\lbrace` / `\rbrace` for set braces; drop `\,` / `\;`; word macros like `\quad`, `\text{ }` are safe.
- Deck LaTeX gotcha (subscripts): the same parser reads `}_{…}` as `_italic_`, silently deleting the underscores so the equation renders as raw `$$`. When a subscript follows `}` or `)`, escape the underscore — `\hat{\rho}\_{\text{w}}`, `\text{AR}\_{\text{dB}}`. Markdown drops the backslash and MathJax gets a normal `_`. Subscripts right after a letter (`E_{x}`) are already safe.
- Deck LaTeX gotcha (line starts): inside a `$$…$$` block, no continuation line may begin with `+`, `-`, or `*` — markdown reads those as list bullets, terminates the paragraph, and splits the `$$` pair, so the slide renders a raw `$$`. Put the operator at the **end** of the previous line instead. Reveal decks only; MyST lesson pages parse `$$` as a real block and are immune, so the *same equation* can render fine on the page and break on the slide.
 - Deck LaTeX gotcha (underscores, context-dependent): in markdown regions escape }_{ as }\_{ — marked pairs two bare _ into <em> and eats them. Inside a raw-HTML block (two-col) do the opposite: marked passes the block through unparsed, so \_ survives and reaches MathJax as a literal underscore. Verified against marked directly.
