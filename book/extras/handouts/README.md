# Printable handouts

Reference sheets served straight off the site root (`html_extra_path` copies
`book/extras/` there, so these land at `<site>/handouts/`).

| File | What |
| :-- | :-- |
| `SmithChart_blank.pdf` | The Complete Smith Chart, letter, black and white. What students plot on. Also bound into the L4 matching lab packet as a work page -- the packet pulls it from here, so there is only one copy. |
| `SmithChart_ZY_colour.pdf` | Combined impedance (red) and admittance (blue) chart, A4. The one to use when a design crosses between $Z$ and $Y$, as the L-match does. |
| `SmithChart_blank.svg` | Vector version of the blank chart, for zooming on screen or reusing as a figure base. |

If you add a handout here, link it from the lesson or lab page that needs it --
nothing indexes this folder automatically.
