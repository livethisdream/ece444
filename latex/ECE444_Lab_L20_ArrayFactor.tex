\question \textbf{Your kit's settings.} Record the Signal Freq that \textbf{Find
HB100} reports and the Rx Gain (dB) that puts the FFT peak at $-10 \pm 3$ dBFS.
Leave the gain there for all three sweeps. Then find the wavelength, the
electrical spacing, and $kd$ at your Signal Freq.

\begin{center}
Signal Freq = \ansbox[1.1in]{$10.3\ \ghz$} \hspace{0.25in}
Rx Gain = \ansbox[1.1in]{as set} \\[10pt]
$\lambda$ = \ansbox[1.1in]{$29.1$ mm} \hspace{0.25in}
$d/\lambda$ = \ansbox[1.1in]{$0.481$} \hspace{0.25in}
$kd$ = \ansbox[1.1in]{$173.2\mydeg$}
\end{center}

\begin{solution}
This key works one nominal frequency, $10.3\ \ghz$, the one the L20 Lab page
uses for its worked example. Accept each cadet's own Signal Freq, anywhere in
the HB100's $10.1$ to $10.7\ \ghz$ range, and check the arithmetic from it.
\eq{ \lambda &= \frac{c}{f} = \frac{3.00\times 10^{8}}{10.3\times 10^{9}} = 0.0291\ \m = 29.1\ \text{mm} \\
     \frac{d}{\lambda} &= \frac{14}{29.1} = 0.481 \\
     kd &= 360\mydeg\ \frac{d}{\lambda} = 173.2\mydeg }
The dry-run kit (phaser-00, 2026-10-19) read $10.408\ \ghz$, where
$\lambda = 28.82$ mm, $d/\lambda = 0.486$, and $kd = 174.9\mydeg$. Its L20 sweeps
ran at Rx Gain $1$ dB with the source about $1.2$ m out; $10$ dB drove the peak
over full scale at $1$ m.
\end{solution}

\begin{solution}

\question \textbf{Written answer 1.} Explain why the first-null beamwidth of the
two-element array is quoted as $180\mydeg$ rather than measured. Name the
condition on $\lambda/2d$ that decides whether a null exists in visible space,
and evaluate it for $d = 14$ mm at your Signal Freq.

\begin{solutionorlines}[2.6in]
For two elements the array factor is $\cos(\psi/2)$ with $\psi = kd\sin\theta$,
so the first null needs $\psi = \pi$, which is $\sin\theta = \lambda/2d$. A null
exists in visible space only when $\lambda/2d \le 1$, that is when
$d \ge \lambda/2$. At the nominal $10.3\ \ghz$ the wavelength is $29.1$ mm, so
\eq{ \frac{\lambda}{2d} = \frac{29.1}{2(14)} = \frac{29.1}{28} = 1.04 > 1 }
and no real angle satisfies the condition. The null exists in the mathematics
but falls outside the range of angles the array can see, so the pattern has no
null anywhere in the scan and the beamwidth between first nulls is quoted as the
full $180\mydeg$ of the scan range. The condition holds at every frequency below
$c/2d = 10.71\ \ghz$, so every HB100 gives the same answer: $\lambda/2d = 1.03$
at $10.408\ \ghz$ and $1.02$ at $10.525\ \ghz$.
\end{solutionorlines}

\question \textbf{Written answer 2.} At boresight the element signals add in
voltage, which predicts a fixed peak step every time you halve the number of
active elements. State the predicted step at four and at two elements, and
compare your two measured steps with it. Leakage through the elements set to 0
and receiver compression were tested on the dry-run kit and ruled out as the main
cause of any shortfall. Propose one other possible cause, and describe a
measurement on your kit that would test it.

\begin{solutionorlines}[2.8in]
Eight equal in-phase signals give eight times the voltage of one, four give four
times, and the plotted peak follows
\eq{ 20\mylog{\frac{N_{\text{active}}}{8}} = -6.0 \text{ dB at } N = 4,
\qquad -12.0 \text{ dB at } N = 2 }
so the ideal step is $6.0$ dB per halving. The dry-run kit read $5.1$ and
$4.8$ dB; expect cadets to report about $5 \pm 1$ dB per halving.

The cause is not yet known, so grade the proposal, not a match to an answer.
Give credit for any cause that the cadet ties to a measurement that could
confirm or rule it out. For reference, the dry run ruled out leakage (with all
eight gains at 0 the peak fell $33.5$ dB below the full array, enough for at most
$0.5$ dB of the shortfall) and compression (lowering every gain from 100 to 50
made the shortfall grow from $2.2$ to $3.4$ dB, where compression would have
shrunk it). Two candidates are still open, and either is a good answer:
\begin{itemize}
	\item The single-element and small-aperture readings read high. Peak Array
	Gain takes the highest of 162 noisy samples, and a nearly flat trace has many
	samples near its top. Test: compare the median of one element's sweep with its
	maximum.
	\item Channel phase or gain shifts with the gain setting, so the signals stop
	adding fully in phase away from the setting used at calibration. Test: measure
	each channel's phase at gains 100 and 50.
\end{itemize}
\end{solutionorlines}
