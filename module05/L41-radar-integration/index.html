Slides

Learning Objectives#

  1. I can integrate FMCW radar processing with a phased-array front-end to track a moving target.
  2. I can suppress a static jammer using null steering while maintaining detection of a moving target.
  3. I can present system performance results and defend engineering trade-offs in a technical briefing.
