Module 3 — Arrays and ADALM-PHASER Beamforming#

Module 03Lessons 15–28

Build beams from elements. Aperture distributions and the array factor, then hands-on beam steering, tapering, beam squint, and null steering on the ADALM-PHASER.

Learning Objectives#

  1. I can describe aperture distributions and calculate aperture efficiency for a given illumination.
  2. I can derive the array factor for an arbitrary linear array and apply pattern multiplication.
  3. I can identify the hardware architecture of the ADALM-PHASER and control it via SDR software.
  4. I can calculate the phase weights required to steer a beam to a given angle and predict the resulting array pattern.
  5. I can implement beam steering on the ADALM-PHASER and verify the steered pattern against theory.
  6. I can distinguish between array factor and true antenna pattern and account for element pattern effects.
  7. I can apply amplitude tapering (uniform, cosine, Chebyshev, Taylor) to control sidelobe level and predict the pattern trade-off.
  8. I can identify beam squint and quantization effects in a phased array and describe their impact on system performance.
  9. I can calculate null-steering weights and implement pattern nulls on the ADALM-PHASER.
